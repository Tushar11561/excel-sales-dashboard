# Sales Performance Dashboard – Excel

## Project Overview
This project demonstrates end-to-end data analysis using Microsoft Excel on real sales data.

## Tools Used
- MS Excel
- Pivot Tables & Pivot Charts
- Slicers
- KPI Metrics
- Data Cleaning & Transformation

## Key Features
- Interactive dashboard with slicers (Region, Category, Year)
- Monthly sales trend analysis
- Region-wise and category-wise performance
- Profit and discount impact analysis

## Business Insights
- West region leads in total sales
- Furniture category shows higher profit margins
- Excessive discounts reduce profitability
